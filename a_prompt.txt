## FIX 1 — Dropdown mouse wheel scroll
On ALL mat-select / dropdown components across the entire app:
Add (wheel)="$event.stopPropagation()" on every mat-select element.
Also add this global CSS:
.cdk-overlay-pane { pointer-events: auto; }
.mat-select-panel { overflow-y: auto !important; }
This prevents page scroll when mouse wheel is used inside an open dropdown.

## FIX 5 — Persist created data across page refresh
The app currently loses created records on refresh (data is stored in memory only).
Fix: after every successful POST/create API call, ensure the list page 
re-fetches data from the API on init (ngOnInit calls the GET list endpoint).
Make sure every list page calls its GET API on ngOnInit and does NOT rely 
on a local in-memory array as the sole data source.
If API is not ready for some pages, store data in localStorage as fallback:
on create → save to localStorage; on ngOnInit → load from localStorage if API fails.
Add TODO comments where real API should replace localStorage fallback.

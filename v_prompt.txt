## FIX 3 — upper-footer buttons must work (Cancel, Save as Draft, Submit)

In upper-footer.component.ts the buttons currently do nothing.
The footer needs to communicate with the active page form.

Create a shared service: src/app/core/layout/footer-action.service.ts

@Injectable({ providedIn: 'root' })
export class FooterActionService {
  private action = new Subject<'cancel' | 'draft' | 'submit'>();
  action$ = this.action.asObservable();
  emit(action: 'cancel' | 'draft' | 'submit') {
    this.action.next(action);
  }
}

In upper-footer.component.ts inject FooterActionService:
onCancel()  { this.footerActionService.emit('cancel');  }
onSaveDraft(){ this.footerActionService.emit('draft');  }
onSubmit()  { this.footerActionService.emit('submit'); }

In EACH create page component ts file inject FooterActionService:
ngOnInit() {
  this.footerActionService.action$.pipe(
    takeUntil(this.destroy$)
  ).subscribe(action => {
    if (action === 'cancel')  this.onCancel();
    if (action === 'draft')   this.onSaveDraft();
    if (action === 'submit')  this.onSubmit();
  });
}
ngOnDestroy() { this.destroy$.next(); this.destroy$.complete(); }

Wire to the existing cancel/save/submit methods already in each component.
If those methods don't exist yet, add TODO comments.

Apply this to all 8 create pages:
mm-deal, portfolio, partners, counterparties,
instruments, gl-master, products, ssi

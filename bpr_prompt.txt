## PAGE: BP Role Assignment
Route: /bp-role-assignment
Page title: "BP Role Assignment"
Breadcrumb: Home › BP Role Assignment

### FORM — Assign Role to BP
Fields:
1. BP ID — searchable input with search icon (lookup from existing BP list API 
   if available, else text input with TODO comment)
2. Role — dropdown (LOV), options:
   - Employee
   - Counterparty
   - Settlement Bank
   - Correspondent Bank
   - Intermediary Bank
   - Broker
   - Clearing Member
   - Custodian Bank
   - Paying Agent
   - Issuer

### CONDITIONAL SECTION — shown only when Role = "Employee"
When user selects Role = "Employee", show these additional fields below:
1. Emp ID — text input, required
2. Designation — text input, required
3. Department — text input, required
4. Date of Joining — date picker, required
5. Date of Leaving — date picker, optional
6. Status — dropdown: ["Active", "Inactive"], required
7. Login User Name — text input, required

When any other role is selected, hide all Employee fields completely.

### BUSINESS RULE
A single BP can be assigned multiple roles.
The list/grid below the form shows ALL role assignments for the entered BP ID.
Grid columns: BP ID | Role | Emp ID | Designation | Status | Actions
Actions column: Edit (pencil icon) | Delete (trash icon)
Edit: opens the row data back into the form for modification
Delete: shows confirmation dialog, then removes the assignment

### BUTTONS
- Save: validates form, saves the role assignment, refreshes the grid below,
  shows success snackbar. If API not ready, add TODO comment and show 
  snackbar "Saved successfully (mock)"
- Reset: clears the form fields

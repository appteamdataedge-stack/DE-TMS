## FIX 2 — tms-select dropdown list cut off (clipped by parent overflow)

FROM DOM: .tms-panel is inside .ssi-row-2 > .de-field > tms-select
The panel is clipped because a parent has overflow hidden/auto.

STEP A — In tms-select.component.scss:
:host {
  position: relative !important;
  display: block !important;
}
.tms-panel {
  position: fixed !important;  /* use fixed to escape any overflow:hidden parent */
  z-index: 99999 !important;
  background: #FFFFFF !important;
  border: 1px solid #E0E0E0 !important;
  border-radius: 8px !important;
  box-shadow: 0 4px 16px rgba(0,0,0,0.14) !important;
  max-height: 220px !important;
  overflow-y: auto !important;
  min-width: 200px !important;
}

STEP B — In tms-select.component.ts find positionPanel() or the method
that sets panel style. Update it to calculate fixed position:

positionPanel() {
  const trigger = this.el.nativeElement.querySelector('.tms-trigger');
  const panel = this.el.nativeElement.querySelector('.tms-panel');
  if (!trigger || !panel) return;
  const rect = trigger.getBoundingClientRect();
  panel.style.top = (rect.bottom + 2) + 'px';
  panel.style.left = rect.left + 'px';
  panel.style.width = rect.width + 'px';
}

Call positionPanel() when isOpen becomes true.
Also call it on window scroll and window resize:
  @HostListener('window:scroll') onScroll() { 
    if (this.isOpen) this.positionPanel(); 
  }
  @HostListener('window:resize') onResize() { 
    if (this.isOpen) this.positionPanel(); 
  }

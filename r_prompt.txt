Open both files:
- src/app/core/layout/bottom-nav/bottom-nav.component.ts
- src/app/core/layout/upper-footer/upper-footer.component.ts

private allowedRoutes = [
  '/mm-deal/create',
  '/portfolio/create',
  '/partners/create',
  '/counterparties/create',
  '/instruments/create',
  '/gl-master/create',
  '/products/create',
  '/ssi/create'
];

ngOnInit() {
  this.checkRoute(this.router.url);
  this.router.events.pipe(
    filter(e => e instanceof NavigationEnd)
  ).subscribe((e: NavigationEnd) => {
    this.checkRoute(e.urlAfterRedirects);

checkRoute(url: string) {

}

## FIX 3 — MM Deal create: sidebar stays fixed while page scrolls
File: mm-deal create component HTML and SCSS

The left sidebar (BASIC INFORMATION section list) must be fixed/sticky
so it does not scroll with the page content.

In the create page layout, the structure should be:
<div class="deal-layout">
  <div class="deal-sidebar">   <!-- sticky -->
    ... section navigation ...
  </div>
  <div class="deal-content">   <!-- scrollable -->
    ... form fields ...
  </div>
</div>

SCSS:
.deal-layout {
  display: flex;
  height: calc(100vh - 100px); /* viewport minus navbar+infobar */
  overflow: hidden;
}
.deal-sidebar {
  width: 220px;
  min-width: 220px;
  height: 100%;
  overflow-y: auto;
  position: sticky;
  top: 0;
  background: #FAFAFA;
  border-right: 1px solid #EEEEEE;
}
.deal-content {
  flex: 1;
  height: 100%;
  overflow-y: auto;
  padding: 24px;
  padding-bottom: 60px;
}

This makes sidebar stay fixed while only right content area scrolls.

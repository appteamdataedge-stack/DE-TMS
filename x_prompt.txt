## FIX 2 — tms-select dropdown list half visible (cut off)

Position is already correct. Only the height/clipping is wrong.
The panel shows partially because a parent has overflow:hidden.

In tms-select.component.ts update positionPanel() to use
fixed positioning so it escapes all parent overflow clipping:

positionPanel() {
  const trigger = this.el.nativeElement.querySelector('.tms-trigger');
  const panel = this.el.nativeElement.querySelector('.tms-panel');
  if (!trigger || !panel) return;
  const rect = trigger.getBoundingClientRect();
  panel.style.position = 'fixed';
  panel.style.top = (rect.bottom + 2) + 'px';
  panel.style.left = rect.left + 'px';
  panel.style.width = rect.width + 'px';
  panel.style.zIndex = '99999';
}

Add HostListeners to reposition on scroll/resize:
@HostListener('window:scroll', ['$event'])
onScroll() { if (this.isOpen) this.positionPanel(); }

@HostListener('window:resize')
onResize() { if (this.isOpen) this.positionPanel(); }

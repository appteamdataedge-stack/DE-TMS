## FIX 1 — User Management: Create User and Create Group buttons not working

Find: src/app/features/user-management/ component files.

Check these causes and fix:
A — Button has type="submit" inside a form but form has no (ngSubmit) handler.
    Add (ngSubmit)="createUser()" on the form tag, OR
    change button to type="button" with (click)="createUser()"

B — The createUser() / createGroup() method exists but is empty or has a 
    return/guard blocking execution. Remove the guard or implement the logic.

C — Button is disabled due to form invalid state even when fields are filled.
    Check [disabled]="form.invalid" — if form has extra validators failing,
    either fix validators or remove the disabled binding temporarily.

D — Router or modal not opening: if clicking should open a dialog/modal,
    check that MatDialog or the modal component is properly injected and called.

Fix whichever cause applies. After fix:
- Clicking "Create User" must open the user creation form/dialog
- Clicking "Create Group" must open the group creation form/dialog
- Saving must add the new record to the list

## FIX 3 — tms-select dropdown list cut off / partially visible

The dropdown .tms-panel is clipped by a parent container with 
overflow: hidden or overflow: auto.

STEP A — In tms-select.component.scss ensure:
:host { position: relative; display: block; }
.tms-panel {
  position: absolute;
  top: 100%;
  left: 0;
  width: 100%;
  z-index: 9999;
  max-height: 220px;
  overflow-y: auto;
  background: #FFFFFF;
  border: 1px solid #E0E0E0;
  border-radius: 8px;
  box-shadow: 0 4px 16px rgba(0,0,0,0.12);
  margin-top: 2px;
}

STEP B — Find parent containers that clip the dropdown.
Search ALL component SCSS files for:
  overflow: hidden
  overflow: auto  
  overflow: scroll
on these classes: .de-card, .dc-main, .dc-panel, .shell-inside,
.de-grid-2, .mm-field, .de-field, .dc-layout, .dc-sidebar

For each found, change overflow to:
  overflow: visible
BUT only if that element does not need scroll for its own content.
If it needs scroll, add instead:
  overflow: visible
  position: relative

STEP C — In styles.scss add:
.tms-panel {
  z-index: 9999 !important;
}
